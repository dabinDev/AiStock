## 字段显示规则

- 价格字段：接口原始值按 `÷1000` 显示，通常保留两位小数。
- 百分比字段：保留两位小数并追加 `%`。
- 金额与市值：按网页风格转为 `亿` / `万`。
- 时间字段：六位整数按 `HH:MM:SS` 显示，例如 `92501 -> 09:25:01`。
- 日期字段：八位整数按 `YYYY/MM/DD` 显示。
- 涨停统计：显示为 `ct/days`，例如 `3/6`。
- 连板数 / 昨日连板数：`1` 显示为 `首板`，大于 `1` 显示为 `N连板`。
- 连续跌停：显示为 `N天`。
- 开板次数、炸板次数：显示为 `N次`。

## 强势股池入选理由映射

- `cc = 1` -> `60日新高`
- `cc = 2` -> `近期多次涨停`
- `cc = 3` -> `60日新高且近期多次涨停`

## 输出结构

```text
<output-root>/
├─ eastmoney_shortline_summary.md
├─ 2026-03-27/
│  └─ shortline.md
├─ 2026-03-26/
│  └─ shortline.md
└─ ...
```

- 每个日期目录只放该日期的日文件。
- 根目录汇总文件按日期倒序重建，不依赖旧汇总内容追加文本。
- 日文件内部包含隐藏元数据注释，供根目录汇总重建使用。
