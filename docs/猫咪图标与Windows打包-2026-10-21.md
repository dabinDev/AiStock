# 猫咪图标与 Windows 完整包

用户提供灰白长毛猫照片，用于生成应用与安装图标，并重新打包当前工作区版本。保留已有界面、分析流程、配置与数据；本轮不提交 Git、不调用真实行情或 Kimi API。

## 交付范围

- 同一猫咪形象的应用图标与安装图标，原图使用内置 imagegen 生成；应用采用灰白猫、炭黑圆角底和暖金细边，安装图标增加小型橙色安装箭头标识。
- 原始透明 PNG 与多尺寸 ICO 保存到项目；ICO 包含 16、24、32、48、64、128、256 像素。
- 应用 EXE、启动窗口、网页标签、安装文件和安装后快捷方式使用对应图标。
- 桌面交付 Windows x64 安装 EXE、完整免安装 ZIP 及 SHA-256。两种版本均包含配套浏览器及全部运行资源，包含最新的 10 秒提示语轮换与绿色页内进度条。
- 安装默认只针对当前用户，程序文件与 `%LOCALAPPDATA%/AstockKanpan` 数据目录分开；卸载程序文件时保留用户数据。

## 验收计划

先补充图标资源集成测试并记录失败，再接入资源与打包配置。执行完整回归，核对 EXE 图标资源及内嵌 HTML/CSS/提示词；从中文空格路径启动解压成品，使用隔离用户目录、假密钥及合成资料验证启动、配置、历史、提示词与重启。安装包采用隔离解包验收模式检查相同文件及图标，不改动本机已有安装或快捷方式。

构建工具使用官方 Inno Setup 的项目内便携编译器，验证签名后使用，不全局安装、不改变 PATH。参考官方文档：[便携模式](https://jrsoftware.org/ishelp/topic_technotes.htm)、[安装图标](https://jrsoftware.org/ishelp/topic_setup_setupiconfile.htm)、[当前用户安装](https://jrsoftware.org/ishelp/topic_setup_privilegesrequired.htm)。

验收证据：`output/package-20261021-131107/`。
